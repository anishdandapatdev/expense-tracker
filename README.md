# Expense Tracker

A cross-platform expense tracking app built with **Flutter** and **Firebase**, following the architecture from the Google Gemini PDF plan.

## Features

- **Authentication**: Email/password sign up and sign in
- **Expenses**: Add, view expenses with category, account, currency, date, and notes
- **Categories**: Create and manage custom categories (e.g. Food, Transport)
- **Accounts**: Track cash, bank, and credit accounts
- **Multi-currency**: Set base currency; expenses in other currencies are auto-converted
- **Analytics**: Pie chart of spending by category for the current month
- **Dark mode**: Toggle in Settings
- **Real-time sync**: Firestore handles offline persistence and multi-device sync

## Tech Stack

- **Flutter** with Riverpod (state management) and GoRouter (routing)
- **Firebase**: Authentication, Cloud Firestore
- **fl_chart** for analytics charts

## Setup

### 1. Firebase Configuration

1. Create a Firebase project at [Firebase Console](https://console.firebase.google.com)
2. Enable **Authentication** (Email/Password sign-in)
3. Create a **Cloud Firestore** database
4. Run FlutterFire CLI to link your app:

```bash
cd expense_tracker
dart run flutterfire_cli:flutterfire configure
```

Select your Firebase project. This generates `lib/firebase_options.dart`.

### 2. Deploy Firestore Rules & Indexes

```bash
firebase deploy --only firestore
```

*(Place `firestore.rules` and `firestore.indexes.json` in your Firebase project root or use `firebase init` to set up.)*

### 3. Exchange Rates (Optional)

For live currency conversion, add a Cloud Function that runs daily and writes to `exchange_rates/latest`. Without it, the app uses fallback rates.

### 4. Run the App

```bash
flutter pub get
flutter run
```

## Firestore Collections

- `users/{uid}` – Profile, base currency, theme
- `expenses/{id}` – Expense entries
- `categories/{id}` – User-defined categories
- `accounts/{id}` – Cash, bank, credit accounts
- `exchange_rates/latest` – Cached FX rates (read-only)
